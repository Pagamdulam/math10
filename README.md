# Математик X — 1-р курс (10-р ангийн агуулга)

Цахим хичээл: 54 хичээл, 54 видео хичээл, суурь мэдлэг, давтлага, түвшин шалгах, сорил, шалгалт.

- `index.html` — үндсэн сайт
- `zereg.html` — 1-р хичээлийн интерактив хичээл (багшийн үзүүлэн)
- `video/01.mp4 … 54.mp4` — видео хичээлүүд (тайлбар нь дэлгэц дээр бичигдсэн)

## Видео байршуулах
GitHub дээр **Add file → Upload files** дарж `video` хавтсыг бүхэлд нь чирж оруулна. Сайт `video/NN.mp4` файлыг автоматаар тоглуулна.

## Дуу оруулсан хувилбараар солих
Дуу нэмсэн видеог **яг ижил нэрээр** (жишээ нь `video/07.mp4`) дахин байршуулахад хангалттай. Сайтыг засах шаардлагагүй.

## YouTube ашиглах бол
`index.html` файлд `const VYT={};` гэсэн мөрийг олоод, жишээ нь `const VYT={1:"abcd1234XYZ",2:"..."};` гэж YouTube-ийн видеоны ID-г бичнэ. Тэр хичээлд YouTube тоглуулагч гарна.

Багшийн горимын кодыг солих: `index.html` файлын `TEACHER_CODE="2026"` гэсэн хэсгийг засна.

## Апп (PWA)
`manifest.webmanifest`, `sw.js`, `icons/` файлууд сайтыг утсанд апп болгон суулгах, интернэтгүй ажиллуулах боломж олгоно. Сайтыг шинэчлэх бүрт `sw.js` доторх `math10-v1`-ийг `math10-v2` гэх мэтээр нэмэгдүүлбэл утсан дээрх хуучин хувилбар хурдан солигдоно.
