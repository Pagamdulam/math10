Сурагчийн дасгал

Өөрийн түвшнээс эхэлж, дуусмагц дараагийн түвшин рүү ахина. Хариуг бутархай (1/8), аравтын бутархай (0,125) эсвэл 10^-5 хэлбэрээр бичиж болно.

Бүхэл илтгэгчтэй зэрэг: товч тэмдэглэл

10.1а · Хичээл тасалсан бол эндээс нөхөж уншаад, «Сурагчийн дасгал»-ын 0-Эхлэл, Суурь түвшнийг бод.

1. Тодорхойлолт (a ≠ 0, n натурал тоо)

a0 = 1   ·   a−n = 1 / an   ·   (a/b)−n = (b/a)n

Сөрөг илтгэгч нь сөрөг тоо биш, урвуу тоо гэсэн үг: 2⁻³ = 1/8. 0⁰ ба 0⁻ⁿ тодорхойлогдохгүй, учир нь 0-д хуваах болно.

2. Зэргийн 5 чанар (m, n бүхэл тоо; a, b ≠ 0)

ЧанарЖишээ
aᵐ · aⁿ = aᵐ⁺ⁿ2⁵ · 2⁻³ = 2² = 4
aᵐ : aⁿ = aᵐ⁻ⁿ7⁵ : 7⁶ = 7⁻¹ = 1/7
(aᵐ)ⁿ = aᵐⁿ(2⁻¹)³ = 2⁻³ = 1/8
(ab)ⁿ = aⁿbⁿ(2x)⁻² = 1/(4x²)
(a/b)ⁿ = aⁿ/bⁿ(2/5)⁻² = (5/2)² = 25/4

3. Бодсон жишээ

  1. 2⁻³ + (3/4)⁻² − (−5)⁰ = 1/8 + 16/9 − 1 = 9/72 + 128/72 − 72/72 = 65/72
  2. (9⁻² · 27³) : 3⁻² = (3⁻⁴ · 3⁹) : 3⁻² = 3⁵ : 3⁻² = 3⁷ = 2187
  3. ((3a⁻²b⁴) / (6a³b⁻¹))⁻² = (½ · a⁻⁵b⁵)⁻² = 2² · a¹⁰ · b⁻¹⁰ = 4a¹⁰ / b¹⁰

4. Түгээмэл алдаа

  • 3⁻² = −9 гэж бичих. Зөв нь 3⁻² = 1/9.
  • −2⁴ ба (−2)⁴-ийг адилхан гэж үзэх. −2⁴ = −16, харин (−2)⁴ = 16.
  • (a + b)⁻¹ = a⁻¹ + b⁻¹ гэж бичих. Зөв нь (a + b)⁻¹ = 1/(a + b).
  • Ижил суурьтай зэргийг үржүүлэхдээ илтгэгчийг үржүүлэх. Илтгэгчийг нэмнэ: a² · a³ = a⁵.

5. Амьдрал дахь хэрэглээ

  • 1 нм = 10⁻⁹ м, 1 мкм = 10⁻⁶ м, 1 мм = 10⁻³ м.
  • Улаан эс 7 · 10⁻⁶ м, томуугийн вирус 7 · 10⁻⁸ м: улаан эс 10² = 100 дахин том.
  • 1 КБ = 2¹⁰ байт, 1 МБ = 2²⁰ байт, 1 ГБ = 2³⁰ байт. C++ дээр pow(2, -3) = 0.125.
